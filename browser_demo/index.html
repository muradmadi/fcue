FCUE — edge decision on the real Privacy Sandbox APIs

This page runs the FCUE edge logic against the actual browser Shared Storage + Private Aggregation APIs — the same flow the Python simulation models. The decision (which coupon?) happens inside a sandboxed worklet that can read the user's local context but cannot phone home; only a noisy, aggregated histogram ever leaves the device.

Requirements to actually run. These APIs are Chrome-only and gated. You need a recent Chrome with the Privacy Sandbox Ads APIs enabled (chrome://settings/adPrivacy, or launch with the relevant --enable-features flags), served over https or http://localhost. Contributions are batched and delayed and sent to a Trusted Execution Environment, so you will NOT see immediate output here — inspect queued reports at chrome://private-aggregation-internals. If your browser lacks support, the buttons below will say so instead of erroring.
